==========================================
  Post Service Deployment Notes
==========================================

Thank you for installing {{ .Chart.Name }}!

Your release is named: {{ .Release.Name }}
Namespace: {{ .Values.namespace.name }}

To get the application URL:

{{- if eq .Values.postService.service.type "NodePort" }}
  export NODE_PORT=$(kubectl get --namespace {{ .Values.namespace.name }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "post-service.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Values.namespace.name }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "Post Service URL: http://$NODE_IP:$NODE_PORT"
{{- else if eq .Values.postService.service.type "ClusterIP" }}
  kubectl port-forward --namespace {{ .Values.namespace.name }} svc/{{ include "post-service.fullname" . }} 8082:{{ .Values.postService.service.port }}
  echo "Post Service URL: http://localhost:8082"
{{- end }}

API Endpoints:
  - GET  /api/posts              - Get feed (paginated)
  - GET  /api/posts/{id}         - Get single post
  - POST /api/posts              - Create post (auth required)
  - PUT  /api/posts/{id}         - Update post (auth required)
  - DELETE /api/posts/{id}       - Delete post (auth required)
  - POST /api/posts/{id}/like    - Toggle like (auth required)

Health Check:
  - GET /actuator/health

Swagger UI:
  - GET /swagger-ui.html

To check the deployment status:
  kubectl get pods -n {{ .Values.namespace.name }} -l app.kubernetes.io/name={{ include "post-service.name" . }}

To view logs:
  kubectl logs -n {{ .Values.namespace.name }} -l app.kubernetes.io/name={{ include "post-service.name" . }} -f
